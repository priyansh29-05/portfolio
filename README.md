# Priyansh Soni — Developer Portfolio

A responsive portfolio showcasing selected frontend and full-stack projects.

**Live portfolio:** https://priyansh-soni-portfolio.netlify.app

## Featured Projects

### ItzFizz — 3D Scroll Experience
A scroll-driven landing page with a 3D metallic torus-knot visual, camera movement, and depth-of-field effects.
- **Live:** https://priyansh29-05.github.io/itzfizz-scroll-animation/
- **Code:** https://github.com/priyansh29-05/itzfizz-scroll-animation
- **Stack:** React, Three.js, React Three Fiber, drei, Vite, CSS

### ARISE — AI Career Recommendation System
Career suggestions, learning-roadmap guidance, and course recommendations based on user-provided skills, interests, and education.
- **Code:** https://github.com/priyansh29-05/ARISE
- **Stack:** React, Vite, Node.js, Express, MongoDB, Google Gemini API

### Mini ERP + CRM Operations Portal
A full-stack application for customer records, inventory, stock movements, and sales challans.
- **Live:** https://mini-erp-crm-portal-ui.netlify.app
- **Code:** https://github.com/priyansh29-05/mini-erp-crm-portal
- **Stack:** React, Node.js, Express, Prisma, PostgreSQL

**Scope note:** The current Mini ERP/CRM version does not enforce granular role-to-module permissions. The portfolio should not claim complete role-based authorization unless it is implemented and tested.

## Skills

React, JavaScript, HTML, CSS, Node.js, Express, REST APIs, MongoDB, PostgreSQL, Git, GitHub, Postman, Vite, and Google Gemini API integration.

## Run Locally

```bash
git clone https://github.com/priyansh29-05/portfolio.git
cd portfolio
npm install
npm run dev
```

Build and preview with `npm run build` and `npm run preview`.
